# Workbench: compact terminal chrome

> 2026-09-06：工作台采用独立 Cobalt 深色外观，与工作台之前的白灰浅色网站分开；终端配色保持独立。手机顶部仅主机栏和终端标题栏两层；工作区/终端切换与设置保留在主机栏，字号和缩放从设置中调整。工作区行高 32px，导航使用中文无衬线字体。三种引擎验证见 [界面验收](../../../docs/ui-appearance-validation-2026-09-06.md)。下文保留 2026-09-05 的历史设计和测量记录；颜色、字体和手机工具栏以本段及 MASTER.md 为准。

> 后续更新（2026-09-05）：顶部增加 32px 的主机选择行，所有主机横向显示为可点击标签，当前主机高亮，溢出时横向滚动；下一层 Tab 栏调整为 28px，侧栏从工作区开始。主机名称可通过顶部铅笔按钮或主机卡片修改。用户已要求移除原版 TUI，所有终端交互统一在 Web Pane 中完成。

2026-09-05 用户要求工作台的视觉风格与终端统一，并缩小侧栏和顶部占用。本页覆盖 MASTER.md 中工作台浅色导航和旧控制权标签的描述；主机管理和登录页仍使用已有样式。

## 设计取舍

- 主内容是长期运行的终端。导航使用终端背景的邻近深色，不再出现大块白色表面。
- 桌面侧栏 184px（原 248px），顶栏 32px（原 51px），Pane 标题 24px（原 28px）。不缩小终端内容换取导航空间。
- Workspace 改为 28px 单行，状态、序号、名称横排；完整名称和计数放在 title 中，多个 Tab 才显示简短计数。
- Agent 保持 40px 两行，保留所属工作区和状态以区分同名 Agent。两组内容紧邻排列，不固定平分侧栏。
- 所有常用操作沿用原入口；顶端即可折叠侧栏，状态持久化。折叠后顶栏仍可展开或打开切换器。
- Tab 使用平直边界和细高亮线，无悬浮卡片与上方空隙，消除默认名称的 `1 · 1` 重复。
- 菜单、设置、搜索、上传提示和手机辅助键沿用同一组语义颜色。
- 等宽字体用于真实终端及其简短导航标记，使用本机字体，不下载装饰字体。导航字号 12px，次级信息 11px。
- 手机及粗指针设备保持至少 44px 点击区域，不能照搬桌面紧凑尺寸。
- 焦点环、图标状态、危险操作确认均保留，布局变化不添加动画。

## 验证目标

1440×900、1024×768、375×667、844×390：记录终端可用区域，检查折叠/展开、长名称、省略提示、主题切换、右键菜单、设置与手机操作。保持 xterm DOM 节点和粘贴处理不受外观改动影响。

## 实测与评估

- 原界面的主要问题：导航与终端明暗割裂、侧栏和顶部占用过大（高）；重复计数与层级空隙、亮色成功提示长期遮挡终端（中）。原有层次、图标、右键菜单和终端主题可以沿用。
- 1440×900 下终端 host 从 1176×805 增加到 1252×840，面积增加约 11.1%；收起侧栏后 host 宽 1436px。
- 1024×768 下 host 为 836×708；375×667 下手机 host 为 375×526，工具按钮为 44×44px。
- 375px、844px、1024px 下文档宽度等于视口宽度，没有页面横向溢出。窄屏终端仍沿用真实行列缩放策略，本次不改变协议或 PTY 尺寸。

## 分屏空白修复

原字号适配循环连续读取旧字格尺寸，并反复乘以 0.97，导致显示网格没有用满 Pane。现先离屏测量字体，按 xterm 的设备像素取整计算最终字号，再于绘制前一次应用，避免跨可见帧试字号。在 2048×1100 双 Pane 的前次验证中，左侧 host 宽 931px、网格宽 920px；扣除左右各 5px 内边距后只剩约 1px 空余（旧网格宽 881px）。BSP 边界和原生 PTY 尺寸保持不变。侧栏闪烁专项验证见 `docs/design/adr/0003-terminal-interaction.md`。
