# Web UI 模式（默认）与 Web Shell 模式

工作台新增 **Web UI 模式**并设为默认：用结构化界面驱动远程主机 Herdr 里的 Claude Code。原来的终端工作台改称 **Web Shell 模式**，能力不变，用顶栏的 **UI / Shell** 开关随时切换（按设备记住，地址栏 `?mode=shell` 只覆盖本次）。两者看同一组工作区和终端，切换不调用 Herdr、不影响远程任务。

- **对话视图**（参考 Cindy 的设计）：每轮的思考、读文件、命令、编辑折叠成一行可展开的工作记录，编辑显示增删行数与 diff，免授权下的高风险命令标红；回答按 Markdown 显示并高亮代码；新回答逐词淡入；跟随最新与「跳到底部」「↓ N 条新消息」。
- **状态栏**：进度、用时、token、实时画面；权限模式胶囊（点击 = Shift+Tab 并读屏确认）；中断按钮（Esc）。
- **交互卡片**替代输入框：提问（含多题、自己填写）、计划审批（批准并保持免授权 / 批准并逐个确认 / 提修改意见）、信任目录。作答前读屏核对对话框未变，按键后未确认不重按。
- **新建 Claude 会话**：选目录、新工作区或标签页、远程主机 `~/.zshrc` 里调用 `claude` 的 alias，工作台生成会话编号启动，首条消息就绪后自动发送一次。alias 在远程主机本地解析，只有名字与免授权/全屏/队友标记传回工作台。
- 非 Claude 终端在 Web UI 中显示只读画面和一行命令输入，「在 Shell 中打开」切到完整终端。第一版对话视图只支持 Claude Code。
- 工作台外观默认改为浅色（已保存过外观选择的设备不变，终端配色默认值不变）。
- Web Shell 的触控/滚轮滚动改为每行发送一次滚轮事件：全屏渲染的 Claude Code、Codex 等程序滚动距离与手势一致（此前只滚约三分之一）。
- 会话记录新增 Claude 的思考块（默认折叠，显示思考耗时）。

Tailcat 主机需要受控端 CLI **v0.1.0-rc.4** 或更新版本才能在新建会话时列出启动器（`~/.local/bin/herdrx update`）；旧版本可手动填写启动器名字，其余功能不受影响。本机和 SSH 主机无需更新。

无需数据库迁移，无新增配置。更新后刷新浏览器或重新打开 PWA。回退只替换网站镜像，数据与身份保留；远程 Herdr 与任务继续独立运行。说明见 [Web UI 与 Web Shell](../web-ui.md)。
