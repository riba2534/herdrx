# 工作台跨端恢复、对话视图与工作区层级

本次集成 PR #6、#7、#8，提供电脑与手机之间的工作台位置恢复、结构化对话与图片附件、可配置语音输入，以及工作区层级和终端自动适配。

## 集成修复

- 返回主机列表保留用户的明确选择；离开页面及时保存位置。慢加载不会覆盖手动选择或阻止之后保存，同一页面的旧请求不能覆盖新位置。
- 工作区分支定期刷新，切换分支或进入 detached HEAD 后同步显示。
- 终端在字体回退为比例字体时改用等宽字体，修复部分 WebKit 环境下列宽异常和不必要的裁剪。
- 对话日志按工作目录筛选后再限制候选数量，修复元数据分页停滞和 Codex 重复消息；限制 DSH 读取内存，并拒绝经符号链接越界或阻塞的非普通文件。
- 语音连接关闭、页面进入后台或登录身份变化时停止采集；过期连接不能把音频或文本带入新登录身份。
- 图片上传状态变化不会阻断已开始的两阶段文本提交；语音空闲超时按实际剩余时间执行。

## 更新与验证边界

更新继续使用现有镜像替换和可见目录挂载方式，保留整个数据目录。新增的位置与写入序号表为兼容附加表，详情见[更新与恢复](../update-and-recovery.md)。关闭浏览器、退出登录及工作台重启仍只断开访问，远程 Herdr 与任务独立运行。

自动化验证覆盖 Go 单元测试、竞态检查、前端类型与静态检查、组件测试、浏览器交互和镜像持久化。每次部署的具体结果与未完成项应按实际验收记录填写；移动视口模拟不能代替真实 Mac、iOS、Android 的 PWA 安装验收，短时断线测试不能代替 72 小时运行。
