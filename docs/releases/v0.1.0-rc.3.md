# v0.1.0-rc.3

远程主机受控端 CLI 的预发布版本，配合当前主分支网站使用。

- Tailcat 主机支持在 Chat 视图读取会话记录：受控端新增只读命令 `herdrx-transcript`，只读固定的 Agent 日志目录，不接受路径参数，逐级拒绝符号链接逃逸；未配对或临时配对凭据不能调用。
- 会话读取新增 Cursor、Gemini、Antigravity CLI、Pi、Grok 与 traex；Herdr 集成上报了该 pane 的会话时自动打开，否则仍由用户选择。
- 访问服务启动时，若默认会话的 Herdr 没有运行，会把它拉起到独立的用户 scope 或新会话；已在运行的 Herdr 不会被接管或重启。设置 `HERDRX_HERDR_AUTOSTART=0` 可关闭。
- 支持 macOS 远程主机（预览）：附带 darwin amd64/arm64 安装包，服务由 launchd 管理。Apple Silicon 已实机验证，Intel 完整用户环境未验收。
- 诊断命令可读取 `herdr --version` 与 API schema，Tailcat 主机的能力探测不再显示 `cli:probe incomplete`。
- 终端观看与尺寸控制分离；`XDG_CONFIG_HOME` 为相对路径时回退到 `~/.config`。

先更新网站，再更新远程 CLI：`herdrx update --version v0.1.0-rc.3`，然后 `herdrx service restart`。GitHub 一行安装方式保持不变。升级只重建访问连接，远程 Herdr 与任务继续运行，已有绑定不需要重新配对。

这是预发布版本；不代表 72 小时稳定性、所有 NAT 类型、Intel Mac 完整环境或真实 Mac/手机 PWA 安装均已验收。
