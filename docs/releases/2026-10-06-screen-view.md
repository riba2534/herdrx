# 画面视图与在远程主机启动 Herdr

本次新增 pane 的**画面视图**：读取 Herdr 已经渲染好的终端文字，按当前窗口宽度折行显示，手机上不必缩小字号就能阅读宽任务的输出，也可以直接选中复制。画面视图只读，不申请尺寸控制、不改变远端 PTY；输入使用底部本地输入框和辅助键。

- 入口：终端工具栏「画面视图」、手机终端角标菜单、切换面板「操作」。视图模式按登录、主机和 pane 记住，刷新后保持。
- 工作台按 pane 读取 `pane.read`（`recent_unwrapped` + `ansi`），只推送变化的行；画面变化时约 300 ms 刷新、静止后放慢，本窗口输入后立即重读；页面隐藏、切到其他 pane 或断线时停止读取。多个窗口查看同一 pane 时共享读取。
- 可切换“原样排版”、调整字号、分步加载更早内容（最多最近 1000 行）。光标、鼠标点击和全屏程序的交互请切回终端。

SSH 主机上的 Herdr 没有运行时，工作台连接遮罩和主机页「Herdr 能力」提供「在远程主机启动 Herdr」。只在用户点击时执行，已在运行的 Herdr 不会被重复启动或重启；远程用户开启 linger 时 Herdr 进入独立的 systemd 用户 scope，否则以新会话脱离 SSH 连接运行。网站仍不提供停止、重启或升级 Herdr 的入口。

终端历史读取按 Herdr 的实际上限请求最近 1000 行（此前请求 10000 行，Herdr 同样只返回 1000 行）。

受控端 CLI 新增启动时自动拉起默认会话 Herdr（独立 systemd scope，`HERDRX_HERDR_AUTOSTART=0` 可关闭），随下一个 CLI 版本发布；本次只更新网站镜像，已安装的 CLI 行为不变。

无需数据库迁移。更新后刷新浏览器或重新打开 PWA。回退只替换网站镜像，数据与身份保留；远程 Herdr 与 pane 内任务继续独立运行。设计与验证见 [画面视图与远程主机拉起 Herdr](../screen-view.md)。
