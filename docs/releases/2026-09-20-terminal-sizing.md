# 多窗口尺寸控制与 Herdr 兼容性

本次将本地显示与共享任务尺寸分开。电脑和手机打开工作台时继续保持远端尺寸；只有明确选择“使用此窗口尺寸”，并收到 Herdr 确认，才控制该终端的行列数。尺寸控制不影响其他已授权窗口输入。

- 展示实际行列数、本站控制状态与释放入口；本站窗口之间可明确确认交接，不强制驱逐未知控制连接。
- 前台续期、后台释放、断线到期；重新打开页面或回到前台先观察，不自动恢复控制。
- 拒绝过期连接、旧控制代次和乱序尺寸消息；观察流保持连续，交接不重放输入。
- 应用滚轮复用本站已有控制连接；没有长期控制时继续保留原生终端四维几何。
- 主机详情分别诊断安装的 Herdr CLI、实际运行的命名会话和各项功能；不自动升级或重启 Herdr。
- 固定真实 Herdr 0.8.2、0.9.0、0.9.1 的兼容回归进入 CI，缺少执行文件或必要测试被跳过均使门禁失败。

像素几何与 ClientShell 的实验记录单独保留。当前产品沿用直接终端 observe/control 语义，观察使用只读原生画布适配器；像素补发会引起额外尺寸变化，ClientShell 输入会取得共享尺寸，因此未启用这些扩展。

无需数据库迁移。更新后刷新浏览器或重新打开 PWA；旧缓存页面申请尺寸控制时收到刷新提示，观察入口保持兼容。回退保留当前数据与身份，仅替换网站镜像。远程 Herdr 与 pane 内任务继续独立运行。

验证结果见 [本轮验证记录](../terminal-sizing-validation-2026-09-20.md)。实体 Mac/iOS/Android 安装与长时间稳定性需独立记录，不能用浏览器模拟代替。
