# Chat 媒体输入（2026-09-13）

本地候选功能记录；不代表公开 Docker Hub 镜像已经发布。

- Chat 图片：粘贴、拖拽、文件选择、可移除缩略图与暂存状态；发送时将文字和图片引用一次提交，支持图片单独发送。上传不再立即写入终端。
- Chat 语音：用户授权后采集，识别文字只追加到草稿，不自动发送。可选独立语音助手音频回复，不代表终端 Agent。
- 管理员配置 OpenAI Realtime 兼容网关，密钥保留在后端；默认关闭，支持会话、音频与频率上限。
- 保留 Terminal / Chat 单开关与原有终端生命周期，以及 SSH 会话读取可重试修复。
- 更新方式和敏感环境文件保留要求见 [更新与恢复](../update-and-recovery.md)；配置见 [媒体输入说明](../voice-input.md)。

验证包括合成音频的真实上游转写及双向音频中继、隔离数据的登录与路由测试。真实手机与 Mac PWA 麦克风授权/音频播放仍需设备验收，不把桌面 Chromium 测试等同于全平台验证。
