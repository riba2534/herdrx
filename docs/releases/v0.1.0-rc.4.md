# v0.1.0-rc.4

远程主机受控端 CLI 的预发布版本，配合网站的 Web UI 模式使用。

- Tailcat 主机支持在「新建 Claude 会话」里列出启动器：受控端新增只读命令 `herdrx-launchers`，在远程主机本地用 `zsh -ic` 运行固定脚本，只回传调用 `claude` 的 alias 名字与免授权/全屏/队友标记；alias 正文（常含网关地址和密钥）不离开远程主机。读取限时 5 秒，超时结束整组进程；不接受参数，未配对或临时配对凭据不能调用。
- 内部命令缺少参数时返回错误退出码，不再可能让访问服务崩溃。

先更新网站，再更新远程 CLI：`herdrx update --version v0.1.0-rc.4`，然后 `herdrx service restart`。GitHub 一行安装方式保持不变。升级只重建访问连接，远程 Herdr 与任务继续运行，已有绑定不需要重新配对。未更新的受控端仍可使用 Web UI，新建会话时手动填写启动器名字即可。

这是预发布版本；不代表 72 小时稳定性、所有 NAT 类型、Intel Mac 完整环境或真实 Mac/手机 PWA 安装均已验收。
