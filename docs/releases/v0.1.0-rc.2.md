# v0.1.0-rc.2

工作台现在可提供受限的内置 DERP 中继。网页连接命令在公网 HTTPS 与实际中继握手可用时优先使用工作台；远程 CLI 再次探测失败会在接入前回退公共中继。默认 HTTP 部署继续使用公共中继。

- 修复首次快照把连接建立与读取共用 20 秒预算的问题；连接默认最多 30 秒，快照另有 10 秒，失败连接会清理以便重连。
- 支持已绑定主机通过签名端点更新迁移中继，保留身份、主机记录与授权。
- 中继限制节点授权、连接数和流量；可选 UDP STUN 默认关闭，网站不管理 HTTPS 证书。
- 网络诊断等待中继确认授权，使用独立诊断身份，避免干扰当前隧道。

先更新网站，再安装本次 CLI。GitHub 一行安装方式保持不变，已有 CLI 可使用 `herdrx update --version v0.1.0-rc.2`。已有绑定需在主机卡片「更新连接端点」复制命令并导入输出包才会迁移；不会在运行期间自动跨区域切换。升级与端点迁移只重建访问连接，远程 Herdr 与任务继续运行。

这是预发布版本；不代表 72 小时稳定性、所有 NAT 类型或真实 Mac/手机 PWA 安装均已验收。

后续主分支还包含一轮工作台体验修复：静态资源压缩与更小的 PWA 预缓存、配对深链与主机表单、中文状态与立即重连、分屏拖拽与 Ctrl+B 快捷键、手机选择/复制文本。条目与验证见 [体验修复 2026-09-11](../ux-remediation-2026-09-11.md)。
