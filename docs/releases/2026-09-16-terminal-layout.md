# 2026-09-16：保留原生终端布局

- 修复打开网页时恢复“自适应”偏好、接管共享终端尺寸并使原生 Herdr 画面裁切的问题。
- 电脑默认“自动”，手机默认“固定字号”。旧的自适应偏好转换为本地显示模式，保留字号和缩放。
- “自适应 · 调整远端尺寸”仍可在当前页面主动选择；界面明确提示它会影响其他窗口，刷新后不自动恢复。
- 旧浏览器资源重连后不能仅凭旧的 responsive 标记取得尺寸控制；普通观察连接继续忽略 resize 消息。

更新网站后刷新标签页或重新打开 PWA。若先前已裁切，退出其他网页的自适应模式后调整一次原生窗口大小即可重新计算布局。此更新不升级或重启远程 Herdr，也不重建 pane 或任务。

验证使用隔离的真实 Herdr 会话与合成原生终端，覆盖打开观察连接、旧请求、显式尺寸控制、分屏、滚动和断开后任务存活；浏览器验证覆盖桌面与手机视口、旧偏好、刷新及主动切换。实体手机安装与长时间运行另行验收。
