# herdrx v0.1.0-rc.1

首个公开预发布版本：在电脑和手机上，通过一个自托管工作台连接多台 Herdr 主机，查看工作区、分屏终端和 Agent 状态，并继续已有任务。

## 主要功能

- 多用户账号、管理员初始化、邀请注册、账号禁用、登录撤销与审计。
- SSH、Tailcat 和管理员本机接入；共享 SSH 密钥、主机文件夹和连接设置。
- xterm 终端、BSP 分屏、历史及全屏应用滚动、中文输入、Shift+Enter 和图片粘贴。
- 桌面与手机布局、独立界面外观、终端字号和缩放、PWA 与 Web Push。
- Linux amd64/arm64 CLI：后台服务、一次性绑定、网络诊断、签名更新、事务回滚与撤销。
- 默认 HTTP 的双架构网站镜像、nonroot 运行、bind mount 持久化和一致性备份。

关闭浏览器、退出登录或网站离线只断开访问。Herdr 和任务独立运行在远程主机，重新进入后连接原会话，不重建任务或重放输入。

## 下载与安装

CLI 附件支持 Linux x86_64 和 ARM64。选择对应压缩包，或使用 `install-herdrx.sh --version v0.1.0-rc.1` 自动选择架构；完整命令见附件 `README-CLI.md`。Herdr 需提前安装并以同一用户独立运行。

Release 同时提供 SHA256SUMS、每架构 Ed25519 签名清单、固定公钥、LICENSE、第三方声明与 SBOM。网站的 Tailcat 安装页会识别完整 Release，提供固定版本命令、架构下载和绑定引导。已有 CLI 可以用 `herdrx update --version v0.1.0-rc.1 --check` 校验此版本。

网站通过 GitHub Actions 构建 Linux amd64/arm64 镜像并发布到维护者配置的 ZOT；公开源码不包含私人镜像地址。自行部署可以配置自己的镜像源，也可以用 Docker 从源码构建，见仓库 README。

## 验证与限制

本地已执行 Go 普通/race/vet、前端与三浏览器回归、双架构原生 CLI/容器、服务生命周期、签名更新/回滚、备份恢复及隔离故障场景。具体范围见 [本地验收](https://github.com/riba2534/herdrx/blob/v0.1.0-rc.1/docs/release-validation-2026-09-07.md)，远端构建结果以 [GitHub Actions](https://github.com/riba2534/herdrx/actions) 为准。

此版本仍为 RC：72 小时持续运行、24 小时关闭全部测试浏览器后的恢复，以及真实手机、跨运营商网络和独立用户操作验收尚未全部完成。长期测试使用固定候选，后续前端入口与发布材料改动单独验证，不把旧候选的运行时长计为新构建已完成验收。

当前支持单实例、可信管理员、每台接入记录一个 owner；不支持 HA、跨账号共享、macOS/Windows CLI 完整服务或复杂 SSH 跳板配置。Herdr 0.8.2 的协议 20 已运行验证，协议 22 仅完成独立报文测试。默认 20 个热连接和 4 个并发拨号是保护上限，不是满负载容量承诺。

PWA 和 Push 按浏览器安全上下文启用；网站默认 HTTP，不附带 HTTPS、证书或域名。真实设备安装能力与网络限制需要在使用环境中确认。完整正式版条件见 [验收清单](https://github.com/riba2534/herdrx/blob/v0.1.0-rc.1/docs/release-readiness-2026-09-06.md)。
