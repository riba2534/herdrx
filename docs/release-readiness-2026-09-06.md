# herdrx 正式版验收清单

范围：Linux amd64/arm64、单实例、可信管理员、每台接入记录一个 owner。当前发行目标为 [v0.1.0-rc.1](releases/v0.1.0-rc.1.md) 预发布；RC 可以提供可安装的公开附件，但不代表以下正式版条件全部完成。

本清单汇总截至 2026-09-07 的本地复核。公开构建与分发由 [主分支 CI](https://github.com/riba2534/herdrx/actions/workflows/ci.yml) 和 [CLI Release](https://github.com/riba2534/herdrx/actions/workflows/cli-release.yml) 记录；流水线不接受未提交源码、失败的主分支 CI 或不同提交的附件。

## 发布时强制执行的门禁

1. 源码、文档和发行公钥已提交；从干净检出重建，生成资源和运行资料不进入 Git。
2. 同一提交的主分支 CI 完成 Go、前端、浏览器、依赖、部署及双架构镜像验证；ZOT 发布只接受通过验收的镜像。
3. CLI 版本标签指向 `main` 历史中的对应提交，完整主分支 CI 已成功；签名私钥与源码固定公钥一致。
4. 两种架构分别在原生 CPU 上验证附件、签名、归档和 CLI 命令；清单与二进制来自同一提交。
5. 先上传 Release 草稿，再下载全部附件并逐项核对摘要，通过后公开。已公开版本不覆盖；RC 不更新 latest。
6. 发布后从公开分发入口完成真实下载、安装、签名检查和网站安装引导验证，保留该版本记录。

维护流程见 [CLI 发布](cli-release.md) 与 [镜像发布](deployment.md)。GitHub 运行记录和 Release 页面是公开分发结果的依据，不能将本地模拟发布替代为真实发布。

- [ ] 在真实 Mac、iPhone 和 Android 上记录浏览器/PWA 的终端操作、软键盘、滚动、中文、图片与通知结果，明确浏览器能力限制。
- [ ] 完成公开附件的新安装、升级和恢复流程后，获得独立用户按文档操作的反馈。

72 小时测试于 2026-09-07 启动，使用单独冻结的运行候选；此记录不预先宣告通过。后续安装入口和发布材料改动分别验证，不把旧候选运行时长算作新构建已完成验收。影响安全、身份、任务存活或连接恢复的修复，需要重新开始受影响的场景。

默认 HTTP，不要求正式域名或本项目部署 HTTPS。localhost 已完成 Service Worker 离线、更新与恢复回归；真实 Mac/手机安装另行记录，不能把浏览器模拟器称为实体设备验收。

## 本轮复审关闭的问题

- 修复首次 SSH 指纹确认和认证失败返回带类型 nil，导致连接池失败清理时网站退出的问题。
- 普通 SSH 非交互 PATH 补充常用 Herdr 安装目录；终端观察进程关闭时显示原因和手动重连，禁止向关闭通道发送或重放输入。
- 撤销先持久化并关闭访问，再最多 2 秒排空 Tailcat TCP 关闭报文，测试必须实际观察到 SSH 连接关闭。
- 修复 Go FileServer 的 index 重定向响应进入 PWA 缓存后无法导航的问题。
- Web Push 强制 HTTPS 443、公网 DNS 校验和固定 IP 建连，禁止重定向与环境代理，淘汰旧无效订阅。
- 安装教程统一为真实 GitHub Release 与签名更新流程；网页只提供附件完整的版本，直接链接相应发行说明。
- 删除登录/主机页底部的应用安装按钮及弹窗，由浏览器菜单提供安装；前端编译产物、测试输出和本地状态按忽略规则管理。

## 正式版退出条件

所有承诺平台和网络范围有可追溯结果，安装、升级、回滚、恢复和撤销可重复，72 小时窗口完成，影响安全、身份、任务存活与恢复的问题清零后，才升级为正式版。

macOS/Windows CLI 完整服务、HA、跨账号共享主机、多网站 controller、复杂 SSH alias/ProxyJump/FIDO/GSSAPI 和代管 Herdr 不在首发范围。
