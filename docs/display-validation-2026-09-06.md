# 字号、缩放与跨端显示验收

日期：2026-09-06。以下结果来自当前源码构建的页面，浏览器连接隔离的 HTTP/WebSocket 测试夹具，不接入用户已有 Herdr 或任务。

## 已实现行为

- 工作台提供 10–28 px 终端字号、50%–200% 终端缩放，以及一键适应窗口。固定字号模式按「字号 × 缩放」显示；适应窗口模式先计算可容纳完整行列的字号，再应用缩放。
- 桌面显示按钮并入当前终端标题栏，展示实际字号；点击字号打开设置，`− / +` 调整缩放，点击百分比恢复 100%，「适应窗口」恢复完整画面。普通桌面将原 34 px 显示栏与 24 px 标题栏合为 32 px 一行，单终端增加 26 px 画面高度；触屏标题栏保持 44 px。窄分屏收起快捷缩放，空间更小时显示选项统一从工作台设置进入。手机通过主机栏的设置按钮调整字号、缩放与显示方式，顶部保留两层导航，见 [界面验收](ui-appearance-validation-2026-09-06.md)。
- 字号、缩放和显示方式保存在当前浏览器，电脑与手机布局分别记忆；手机默认保持 14 px 可读字号，电脑默认固定 14px 字号（超出可滚动，点「适应窗口」可一次看全）。损坏或越界的存储值会恢复默认值或限制在有效范围内。
- 放大后的画面在终端内部滚动，支持滚动条、触控板及手机单指滑动。终端初次显示时定位到光标；键盘按钮可回到光标并聚焦输入。
- 手机横屏保留单终端布局，可从切换面板选择不含 Agent 的普通终端，也可通过按钮打开终端操作菜单。历史按钮及上一屏、下一屏支持触屏查阅记录。
- 控件适配 44 px 触摸目标和安全区域；可视视口因软键盘缩小时收紧布局、保留辅助键，设置面板仍可滚动。浏览器原生缩放快捷键与双指缩放保持可用。
- 显示设置仅改变浏览器内的字体和滚动位置：保留当前终端观察流、来源行列数，不发送终端输入、远程 resize 或关闭操作。

## 验证边界

浏览器运行于 Linux，手机和平板采用浏览器设备模拟；未在实体 iPhone、Android 或 macOS Safari 上操作。软键盘覆盖的是浏览器可视视口事件与布局响应，不等同于实体设备上的输入法、地址栏和系统键盘验收。这里的「200%」布局用等效 CSS 视口验证，浏览器缩放快捷键的保留另有单元测试。

## 鼠标滚轮修复补充

复现原因：全屏应用可能没有 Herdr 主机历史，`pane.read` 此时只返回当前画面。此前网页对向上滚轮一律读取历史，并暂停实时画面，导致 Claude 等全屏应用看起来无法滚动。另一个问题是 Herdr 历史快照使用 LF 分隔，直接写入 xterm 会保留前一行的列位置，造成历史文字错位。

- 有主机历史时，读取 Herdr 保留的近期内容，在浏览器内连续上下滚动；仅对历史快照补齐 CRLF。
- 无主机历史时，将手势交给 Herdr 的原生 `terminal.scroll`，由 Herdr 决定应用鼠标、备用屏幕按键或主机历史的路由。连续手势合并发送，失败和换流后不重放。
- 原生滚动通过临时 control 通道发送，等待接入成功再写入；连续手势复用通道，停手 250 毫秒后释放并等待关闭。保持 Web 观察流，不抢占已有 controller。使用 Herdr 来源布局尺寸，浏览器字号和缩放不作为远程尺寸。
- 滚轮监听覆盖整个终端画面区域；放大时先移动可见画面。Ctrl/Meta 缩放、Shift 和水平手势保留浏览器行为。历史按钮在无主机历史时也走原生滚动，避免停在当前画面的副本上。

三种浏览器引擎均通过真实滚轮事件回归：全屏应用向上/向下手势发出原生滚动请求；普通历史连续两次向上和一次向下时，实际首行随之变化；LF 历史行保持列对齐。测试同时检查未误发字符输入、resize 或关闭 pane。

隔离的真实 Herdr session 内运行备用屏幕和 SGR 鼠标应用，验证向上/向下事件确实到达应用、任务 PID 在控制释放后保持不变，以及已有 controller 被拒绝抢占后仍可输入。测试先建立原生布局再启动应用，滚动前后为相同的 94×39 网格。取消待接入控制请求和登录过期后的滚轮请求另有 Go 回归。

原生 control 接入会让 Herdr 按传入的来源布局应用尺寸，并短暂持有该终端的尺寸控制；因此，这一滚轮实现不能宣称与显示设置一样「完全不触发 Herdr 尺寸处理」。尚未建立原生布局的纯 headless pane 首次接入可能从默认尺寸调整到布局尺寸。已有 controller 占用时会显示错误，用户释放控制后可重试。

真实 Herdr 测试需显式指定二进制，未指定时跳过；三种浏览器回归已纳入 CI。该测试不替代 SSH/Tailcat 跨网滚轮或实体手机验收。

```bash
HERDRX_TEST_HERDR=/path/to/herdr go test -count=1 -run 'TestScroll' -v ./internal/herdr
```
