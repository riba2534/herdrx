# Agent 总览与已读标记

Agent 总览（`/agents`）汇总当前账号所有主机上 Herdr 识别到的 Agent，入口在主机列表顶栏和工作台顶栏的机器人图标；图标上的数字是“需要你”区的条数。

## 分组与排序

| 分组 | 条件 |
|---|---|
| 需要你 | Herdr 报告 `blocked`（权限确认、提问、计划审批等待输入），或 Agent 已完成而你还没在网页里看过这一轮 |
| 工作中 | Herdr 报告 `working` |
| 已看或空闲 | 已完成且看过，或 `idle`；状态未知的也放在这里。默认折叠为“还有 N 个空闲” |

同一分组内按主机名称、工作区与标签页顺序排列。每行显示 Agent 名称与终端标题、主机名 · 工作区 › 标签页，以及工作目录的最后一级。点一行打开该主机工作台并聚焦对应终端（`/h/<主机>?pane=<终端>`）。

页面在前台时每 5 秒刷新一次，切到后台或锁屏后停止，回到前台立即刷新。每台主机单独读取，最多等 8 秒；某台主机连不上、Herdr 未运行或超时，只在“无法读取的主机”里列出原因和“打开主机”按钮，其他主机照常显示。刷新失败时保留上一次的结果并提示。

已安装为应用且浏览器支持角标时，打开总览或工作台会把图标角标设为“需要你”的条数，没有时清除。

## 已读标记

“看过”是 herdrx 自己按账号保存的标记，不写入 Herdr，也不影响原生 Herdr 或其他账号的显示：

- 工作台里某个终端出现在屏幕上、且页面处于前台约 1 秒后，记下该 Agent 当前这一轮（Herdr 的 `state_change_seq`）。手机只算当前显示的终端，电脑算当前标签页的所有分屏。
- 只有标记等于 pane 当前的序号才算看过。Agent 开始新一轮后序号变化，完成后会重新出现在“需要你”；Herdr 重启后序号从 0 重新计数，旧标记不会把新一轮误判为已看。
- 页面在后台、关闭或离开时不会记录，也不会调用任何 Herdr 操作；记录失败不提示，下次看到该终端时再记。
- 终端在 Herdr 中关闭后，下一次读取总览时清理它的标记。删除主机会一并删除该主机的标记。

总览只读取 Herdr 状态，不会启动、停止或向 Agent 发送任何输入。
