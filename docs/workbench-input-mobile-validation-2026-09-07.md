# 工作台输入与手机布局验证

## 修复范围

- 终端输入改为每个浏览器窗格一个有界队列，同时只执行一个 `pane.send_text`。等待远程响应期间收到的按键合并发送，保留顺序、中文、转义序列和粘贴字节；WebSocket 继续接收按键、回显确认和心跳。
- 每次请求最多 64 KiB，不拆分 UTF-8 字符；待发送输入最多 4 MiB。输入失败或超限会关闭对应 Web 终端连接并提示手动检查、重连，不自动重放。浏览器离开、观察流退出或权限撤销会丢弃待发送输入。同一工作台内切换标签页或窗格时，先送完已经接收的按键再关闭旧观察流，避免刚按下 Enter 就切换时丢失提交。
- 桌面侧栏提供可见的“＋ 新建”，工作区及 Agent 名称允许换行，状态文字保留完整宽度。创建结果早于快照到达时，新工作区选择不会退回旧位置。
- 手机提供工作区、新建、横向标签页导航和分屏切换入口；默认“自适应”以 14px 字号按可用空间计算列数和行数，让远端程序重新换行。切换为“原始画面”保留源画布并允许平移。旧浏览器偏好迁移到自适应，保留原有字号；后续选择独立保存。
- 手机内容区使用纵向弹性布局，终端占用导航和辅助键之外的剩余空间；删除主题样式中重复的内容区行定义。横屏及软键盘弹出时压缩导航，切换入口仍可用。辅助键增加 Enter，操作时保留终端输入焦点。

## 验证与边界

`internal/herdr/input_test.go` 使用每次 RPC 延迟 150 ms、每 20 ms 输入一个字符的可复现测试。24 个字符逐个调用时等待时间 p50 约 1.71 s、p95 约 3.01 s；合并后 p50 约 230 ms、p95 约 290 ms。这是模拟远程调用延迟的对比，不是实际公网或手机端到端延迟。

`internal/httpapi/input_queue_test.go` 通过真实 WebSocket 和隔离 Unix socket 阻塞输入响应，验证等待期间心跳可响应；远端报错后，浏览器收到终端关闭原因，积压输入不会继续发送。

`HERDRX_TEST_HERDR` 启用的真实 Herdr 集成测试使用临时配置和独立会话，校验中文、emoji、方向键、Shift+Enter、Ctrl+C 与多行粘贴的原始字节。关闭输入队列后，原 pane 和 PTY 尺寸保持不变。

浏览器回归覆盖 Chromium、Firefox、WebKit，手机 320×720、390×844、横屏 844×390，平板 768×1024、1024×768，以及窄桌面窗口。检查长名称与状态无裁切、新建后的选择、隐藏侧栏偏好、终端可用面积、自适应与原始画面切换、触摸平移、软键盘视口事件和辅助键焦点。渲染、滚动和闪屏测试继续覆盖终端显示。

Go vet、全量 race、前端类型检查、lint 与 87 项单元测试通过。桌面浏览器自动化不能打开真实手机系统键盘；实体 iPhone/Android、真实 PWA 安装及不同运营商网络仍按正式版验收清单记录，未将模拟器结果视为实体设备验收。

## 手机终端自适应补充验证

此前手机只调整页面布局和本地缩放，295 列远端终端仍会超出窄屏。当前版本通过显式 `responsive` 观察流选项申请 Herdr 控制客户端，以保持可读字号的行列数打开终端；窗口、字体或键盘视口变化时复用连接发送 resize，按响应帧尺寸解析 ANSI。普通电脑显示及本地缩放继续使用观察客户端，不调整远端尺寸。

自适应视图不使用 takeover，不抢占其他控制客户端；已被占用时提示关闭另一个自适应窗口后重连，或切换到原始画面。滚动复用当前控制连接，避免另开控制客户端引起占用失败或尺寸回跳。输入仍经有序队列发送。退出只关闭访问客户端；无原生窗口的会话可能保留最后的 PTY 尺寸，不承诺自动恢复桌面宽度。

- `scripts/test-workbench-display.mjs` 在 Chromium、Firefox、WebKit 中以 295 列源画布复现，覆盖 479×847、390×844、320×720、横屏与模拟键盘视口。断言默认字号保持 14px、最右侧与最底行标记可见、屏幕尺寸不溢出、旋转与键盘变化不重开连接。
- 前端单元测试验证从 295 列调整到手机列数，修改字号重新计算行列数；布局快照更新不重复打开控制连接。偏好测试覆盖旧版本迁移和用户主动退出自适应后的持久化。
- `HERDRX_TEST_HERDR` 启用的 `TestResponsiveTerminalWithRealHerdr` 使用真实 WebSocket/API、独立 Herdr 和响应 SIGWINCH 的程序，验证 56×30 → 40×18 重绘、滚动复用、占用保护、连续关闭重开，以及浏览器关闭后原 PID、pane 和输入仍存活。本机以 race 检测通过；CI 未安装真实 Herdr 时明确跳过此项。
- 固定画布的触摸、历史与逐帧防闪屏回归继续通过，独立于自适应尺寸验证。
