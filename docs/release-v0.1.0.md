## 2026-09-06 中文终端列对齐修复

修复中文全角标点使终端背景边缘和表格边框出现阶梯错位的问题。浏览器的标点间距压缩会干扰 xterm DOM 渲染器的重复字符测宽；终端及其测量元素统一使用 `text-spacing-trim: space-all`，并关闭自动中西文间距，保留固定字符列。属性语义见 [CSS Text 规范](https://www.w3.org/TR/css-text-4/#propdef-text-spacing-trim)。

新增真实 Chromium [渲染回归](../scripts/test-terminal-rendering.mjs)，覆盖中英文及全角标点、粗体/斜体、小数字号和 DPR 1/2。测试使用合成 ANSI 画面，不包含真实终端内容；未修复版本在标点密集用例中出现超过 200 px 的错位，修复后通过固定列对齐检查。

## 明确边界

- v1 单实例、可信管理员，不支持主机共享或 HA；
- SSH v1 覆盖 host/port/user/key/password，不覆盖本机 SSH alias、ProxyJump、FIDO/GSSAPI；
- 公共 tailcat.dev 仅供试用，生产推荐独立公网 IP 自建 DERP；
- 当前结构状态每 2 秒用 fresh snapshot 收敛，避免 herdr 0.8.2 无统一 revision 的历史事件回放导致状态倒退；
- 浏览器原生保留快捷键仍受浏览器限制，PWA 独立窗口体验更完整。


## 字号、缩放与跨端显示

工作台新增终端字号与缩放设置、常驻缩放按钮和一键适应窗口，显示偏好在当前浏览器持久化，电脑与手机布局分别记忆。手机默认使用可读字号并支持滑动查看完整终端；标题栏可回到光标打开键盘、查看历史和打开终端操作菜单。横屏、平板触控及可视视口缩小后的布局同步适配。

改变显示设置保留现有终端观察流和远程行列数，不发送输入或远程 resize。验证方式与范围见 [跨端显示验收](display-validation-2026-09-06.md)。

鼠标滚轮已区分普通主机历史与全屏应用：普通历史支持连续上下滚动并修正 LF 换行错位；无主机历史时通过 Herdr 原生滚动路由操作应用。三种浏览器的真实滚轮事件和隔离真实 Herdr 的鼠标事件、任务存活、控制占用检查通过。临时 control 接入的来源尺寸处理及未验收范围见上述报告。

连续滚动进一步复用短时控制通道，并按浏览器刷新节奏发送手势，避免每批滚动重复接入和等待上一批网络应答。停手后自动释放；慢连接下限制在途请求，并丢弃过时的未发送手势。前后对比及模拟网络延迟结果见 [滚动响应验收](scroll-performance-validation-2026-09-06.md)。

## 网站与终端界面分离

登录、主机列表、访问管理使用白灰浅色网站界面，打开工作台后使用 Cobalt 深色终端界面。两部分分别保存外观，通过按钮在浅色与深色间直接切换；同类页面跨标签同步，终端配色独立。桌面主机页采用可搜索列表，手机采用紧凑卡片；后台用户身份、角色状态与操作对齐。手机顶部收紧为两层，字号和缩放移入设置。三种浏览器的跨端界面与终端交互回归通过，范围见 [界面验收](ui-appearance-validation-2026-09-06.md)。

## 2026-09-07 SSH 密钥与主机文件夹

新增账号独立的共享 SSH 密钥管理，支持导入/拖入 OpenSSH 或 PEM 私钥、加密私钥口令、生成 Ed25519 密钥、公钥与指纹、可选 SSH 用户证书；多台主机可选择同一密钥。已有 SSH 主机可修改用户名、端口和密码/密钥认证。主机文件夹支持子文件夹、移动与删除保留内容。SQLite 升级为 schema 3，旧主机和凭据保留。真实 SSH 握手、用户隔离、三种浏览器和持久化验收见 [功能说明](ssh-keys-and-folders.md)。

## Tailcat 安装与绑定引导

添加 Tailcat 主机现按「安装 CLI → 后台运行 → 绑定主机」推进，第一步检查 GitHub Release 并提供对应版本的复制命令、架构下载链接；后台步骤包含 setup/status、linger 与排障；最后一步使用一次性凭据完成已有的安全绑定，支持刷新续接。已有 SSH、本机和终端生命周期不变。

新增 Linux amd64/arm64 CLI 压缩包构建脚本、SHA-256 安装器、离线教程及独立 GitHub Release 流水线。安装失败保留旧 CLI，重复安装幂等；setup 迁移失败不再生成替代身份，connect 不再误报登出保活。源码未提交时的包明确标记为候选，发布脚本拒绝发布。见 [接入教程](tailcat-quickstart.md) 和 [发布说明](cli-release.md)。

## 本机发布修复（2026-09-07）

默认部署仅运行 HTTP 网站，发布附件不再附带 Caddy、TLS 配置或证书目录。HTTPS 由部署者自行选择反向代理提供；本机测试与发布准备不要求域名。

共享主机连接增加并发拨号合并、可配置连接上限、失败退避和持续快照恢复。通知采集与发送分别限制并发，清理失效状态并保持账号撤销即时生效。受控端增加自建 DERP 配置、分层网络诊断和原身份签名的端点迁移，已有绑定可在更换中继后恢复。

安全依赖更新到已修复的 SSH/HTTP/JWT 版本；中继拨号固定经过校验的 DNS 地址，公开输入不能开启测试用证书跳过选项。本机回归记录与仍待执行的容量、跨网和长期运行项目以 [发版清单](release-readiness-2026-09-06.md) 为准。

CLI 发行链增加固定 Ed25519 公钥、每架构签名清单与 GitHub 下载更新。更新校验兼容性和时效，候选自检后切换并检查本地就绪，失败恢复旧服务；同版本重试保留回退点，回滚不修改当前身份和撤销记录。清单、归档和发布脚本均有篡改及失败场景回归。

最新本地验收补齐 Linux amd64/arm64 原生 systemd 生命周期、旧服务迁移、签名升级和回滚，以及双架构网站容器运行、备份恢复、容量和 PWA 更新恢复。对应源码和证据范围见 [2026-09-07 验收](release-validation-2026-09-07.md)。历史段落中的未执行项按该记录更新；公开 CI、分发和长期跨网验收仍未完成。

Web Push 订阅和发送增加独立出站策略：HTTPS 443、公网 DNS 校验与固定地址建连、无重定向、无环境代理；阻断用户指定通知 URL 访问工作台内网。

修复首次 SSH 指纹确认或认证失败后，连接池关闭空端点导致网站退出的问题；真实 SSH 首次信任、错误密码，以及网站重建和 UDP 阻断/恢复后的原会话读取通过隔离回归。
