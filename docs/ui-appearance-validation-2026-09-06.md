# 网站与工作台外观、跨端布局验收

日期：2026-09-06，更新于 2026-09-07。

登录、主机列表、访问管理和配对页采用常规网站样式，默认白灰浅色；进入工作台后默认使用 Cobalt 深色终端界面。两部分的外观分别保存，互不覆盖，并各自通过按钮在浅色与深色间直接切换。终端 ANSI 配色与等宽字符网格独立保留。

## 已实现

- 登录页使用简洁表单、统一顶部标识和主题切换按钮。初始化、邀请注册、注册关闭与已有账号登录行为保留。
- 网站顶部统一为单行：普通桌面从 64 px 收紧到 44 px，触屏 52 px，按钮至少 44×44 px。用户名与角色横向排列，长名称省略；窄屏用带可访问名称的图标按钮保留主题、密钥、管理和退出。
- 桌面主机页采用紧凑列表，手机采用单列卡片；支持名称、地址和接入方式搜索。Tailcat 显示连接说明，避免把它当作 SSH 地址拼接出空字段。
- 访问管理分开呈现用户身份、角色/状态和操作；账号 ID、创建时间收进可展开详情。注册开关、筛选、邀请、审计和 Web 登录管理保持可用。
- 手机工作台顶部从四层收紧为主机栏和终端标题栏；工作区与终端切换、设置保留在主机栏，字号与缩放通过设置面板调整，底部保留辅助键。
- 桌面字号、缩放与适应窗口并入当前终端标题栏，普通桌面合并为 32 px 一行，单终端增加 26 px 画面高度。控件随当前分屏切换，长标题省略、窄分屏收起快捷缩放；所有显示选项仍可从工作台设置进入，触屏标题栏保持 44 px。
- 网站与工作台分别保存主题，刷新后恢复、同类页面跨标签页同步；只有浅色和深色，不随操作系统自动变化。旧版“跟随系统”偏好回到对应页面的默认值。旧版全站主题不会覆盖网站浅色/工作台深色的默认分工。加载脚本先按入口设置外观，登录状态确认后在绘制前切换到实际页面所属外观。

## 验证

`scripts/test-app-appearance.mjs` 使用构建后的真实 React 页面及隔离 HTTP 数据，覆盖 Chromium、Firefox、WebKit：

- 1440、768、736、390、320 px 宽度的登录、主机列表、密钥和访问管理，深浅两套主题无页面横向溢出。
- 单次点击、Enter/Space 键切换主题，刷新恢复、跨标签同步；系统主题变化不会覆盖明确选择，旧“跟随系统”值回退为页面默认外观；浏览器存储被禁用时本次访问仍可切换。
- 主机页进入工作台默认由浅转深、返回恢复浅色；两个标签页分别修改网站和工作台设置互不覆盖；停留在工作台地址时登录失效，登录页恢复网站外观。
- 主机搜索与清除、重命名及 Escape 后焦点恢复、SSH/Tailcat 表单布局。
- 管理员与普通用户的主机和管理入口差异，账号详情、Web 登录区、邀请与审计栏目。

该测试已接入 CI 的浏览器验证步骤，在推送和 PR 检查中与认证、终端渲染及工作台显示回归一同执行。

`scripts/test-workbench-display.mjs` 在三种引擎中检查手机顶部两层布局、设置可达性、44 px 触摸按钮、横竖屏和平板、真实滚轮、历史翻页、触摸横移、软键盘视口事件、字号/缩放持久化及键盘焦点。新增工作台界面主题切换检查，确认终端颜色、观察流和来源尺寸保持稳定。

70 项前端单元测试、TypeScript、lint 和前端构建通过。真实网站认证脚本也通过，覆盖初始化、注册开关、重启持久化、权限、跨标签登录退出、用户禁用和跨域拒绝。

## 复现与边界

```bash
make web-build
HERDRX_TEST_ENGINES=chromium,firefox,webkit node scripts/test-app-appearance.mjs
HERDRX_TEST_ENGINES=chromium,firefox,webkit node scripts/test-workbench-display.mjs
```

浏览器均运行于 Linux；手机和平板采用视口与触摸模拟，未代替实体 iPhone、Android、macOS Safari 或系统软键盘验收。界面检查使用合成账号、主机和终端数据，不连接用户现有 Herdr 或向真实 pane 输入。认证回归另用独立数据目录和网站进程。
