# Web UI 模式与 Web Shell 模式

工作台有两种模式，**默认是 Web UI 模式**。两者看的是同一份 Herdr 工作区、标签页和终端，切换只改变网页的显示方式，不会重启终端、不会调用 Herdr、也不会影响远程任务。

| 模式 | 适合做什么 |
|---|---|
| **Web UI** | 用结构化界面驱动 Claude Code：看对话和工作过程、回答提问、批准计划、发消息、新建会话。非 Claude 的终端显示只读画面和一行命令输入 |
| **Web Shell** | 原来的完整终端工作台：分屏、Herdr 快捷键、尺寸控制、滚动、图片粘贴，适合 vim、Codex 等任何终端程序 |

电脑上在顶栏、手机上在顶部右侧的 **UI / Shell** 开关切换。选择按设备记住；地址后加 `?mode=shell` 或 `?mode=ui` 只对这次打开生效。Web UI 里非 Claude 终端的「在 Shell 中打开」、对话视图里的终端按钮，会切到 Web Shell 并保持选中同一个终端。

第一版 Web UI 只为 **Claude Code** 提供对话视图。Codex 等其他 Agent 继续在 Web Shell 里使用，Agent 总览和通知照常覆盖它们。

## 对话视图

数据来自 Claude Code 自己写在远程主机上的会话记录，不是终端文字，所以每一轮都按真实的角色和工具调用显示（界面参考了 [Cindy](https://github.com/makecindy/cindy) 的设计）：

- **一轮一段**：你的消息在右侧白色气泡里；Claude 的回答不加框，按 Markdown 显示（代码高亮、复制、长代码可折叠、表格横向滚动）。
- **工作过程折叠**：一轮里的思考、读文件、搜索、命令、编辑收成一行「已工作 3m · 读取 12 个文件 · 运行 4 条命令」，点开逐条查看；编辑类工具显示增删行数和 diff，命令显示输出（过长时截断，可展开全部）。工作中只露出最近几步和计时。
- **高风险标记**：免授权模式下命令会自动执行，`sudo`、`rm -rf`、`git push --force`、`curl … | sh` 之类的命令在工作记录里标红，便于事后检查。
- **跟随最新**：停在底部时自动跟随；往上翻后停止跟随，出现「跳到底部」或「↓ N 条新消息」。
- 新到达的回答逐词淡入；系统开启“减少动态效果”时不播放。

会话记录要求远端装有 Herdr 的 Claude 集成（自动认出当前会话），或在视图里手动选择一次。读取方式与原 Chat 视图相同：本机、具备 Python 3 的 SSH 主机，以及受控端 CLI v0.1.0-rc.3 或更新版本的 Tailcat 主机。

## 运行状态与交互卡片

输入框上方是状态栏：

- Claude 工作时显示它正在做的事、已用时间和 token 数，可展开「实时画面」查看终端里最新打出的几行文字（纯文本）。
- **模式胶囊**显示当前权限模式（免授权、自动、手动确认、接受编辑、计划）。点一下相当于在终端按一次 Shift+Tab，切到下一个模式，并读取终端确认结果。
- 工作时显示「中断」，相当于在终端按 Esc。

Claude 需要你回答时，卡片会替代输入框（草稿和已选图片保留），可收起成一条细栏：

| 卡片 | 内容与操作 |
|---|---|
| 提问 | 题目、选项与说明直接来自 Claude 的提问；数字键快捷选择；「自己填写答案」先选中填写项，再在卡片里输入文字提交；多题时显示「第 n/m 题」，最后确认提交。多选题请到 Web Shell 处理 |
| 计划审批 | 显示计划全文；「批准并保持免授权」「批准，改动逐个确认」「提修改意见」（输入意见后提交，Claude 会按意见修改计划） |
| 信任目录 | Claude 第一次进入某个目录时询问是否信任；「信任此目录并继续」或「退出」 |
| 其他对话框 | 按读屏结果显示可点选的选项 |

每次作答前，工作台都会重新读取终端，确认对话框没有变化才按键；对话框已经变化（例如已在电脑上回答）时什么都不按，并提示重新选择。按键后约 15 秒没有确认到结果，会提示查看终端，**不会自动重按**。计划审批时 Herdr 可能仍显示“空闲”，卡片以 Claude 的会话记录为准。

## 新建 Claude 会话

Web UI 的顶栏和侧栏提供「新建 Claude 会话」：

1. **目录**：远程主机上的绝对路径，可从当前各终端的目录中选择。
2. **位置**：新建工作区，或在当前工作区里新建标签页。
3. **启动器**：远程主机 `~/.zshrc` 里调用 `claude` 的 alias，带「免授权」「全屏」「队友」标记；默认选这台主机上次用过的。
4. 标签名和首条消息可选。

工作台在新终端里输入 `<启动器> --session-id <编号>` 启动 Claude，会话编号由工作台生成，所以对话视图能准确打开这个会话。首次进入目录时先弹出信任卡片；首条消息在 Claude 就绪后自动发送一次，结果不确定时不重发，文字会留在输入框。

**启动器的读取方式与隐私**：工作台在远程主机上用 `zsh -ic` 运行一段固定脚本，在远程主机本地检查每个 alias，只把名字和三个标记传回工作台。alias 正文（常包含网关地址和密钥）不会离开远程主机，也不会写入数据库、日志或审计记录。读取最多等 5 秒，超时会结束整组进程。

- 远程主机没有 zsh、读取超时，或 Tailcat 受控端版本过旧（需要 v0.1.0-rc.4 或更新）时，启动器一栏变成可编辑文本框，默认 `claude`，可手动填写 alias 名字。
- `.zshrc` 在交互启动时会执行的命令（例如自动进入 tmux）可能拖慢或影响读取；读取没有终端（stdin 为空、`TERM=dumb`），大部分自动进入逻辑会跳过。

## 边界

- Web UI 不注入 Claude hooks，不修改远程主机的 `~/.claude/settings.json`；你自己在终端里开的 Claude 也能在 Web UI 里查看和作答。
- 模式切换、关闭页面、断网、退出登录都不会关闭终端或结束 Claude；关闭终端、标签页、工作区仍需要明确确认。
- 中断、模式切换、卡片作答都是按键操作，效果以终端实际状态为准；需要精确操作时切到 Web Shell。
